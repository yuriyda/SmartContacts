# Smart Contacts — Plan P2: CRUD + Desktop UI core

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Make Smart Contacts a working desktop contacts manager: real CRUD, the full TaskOrchestrator-style three-pane layout (Sidebar + Main list + Detail panel), Settings dialog, demo data generator (50 × 2 locales), Backup/Restore, and the StatusBar with live counters and theme/density toggles.

**Architecture:** All business logic lives in `shared/`. UI is React + Tailwind, with theme classes coming from `@shared/themes` and translations from `@shared/i18n`. Visual style is a port of TaskOrchestrator's UI patterns (`Sidebar`, `StatusBar`, `SettingsDialog`, `DetailPanel`, `common.tsx`) — same structure, same density modes, same dark/light × default/gruvbox themes, just with contacts-shaped data.

**Tech stack:** TypeScript strict, React 18, Tailwind, lucide-react. No new infrastructure.

**Reference (read-only):** `/workspace/TaskOrchestrator-main/tauri-app/src/ui/`, `/workspace/TaskOrchestrator-main/tauri-app/src/core/`, `/workspace/TaskOrchestrator-main/shared/core/`. Copy the UI grammar and color choices; replace data shape from Task to Contact.

**Spec:** `docs/superpowers/specs/2026-04-29-contacts-app-design.md`. P2 implements §3 row mappers, §8 desktop UI (excluding QuickEntry which is P3), §9 (Settings dialog tabs General / Custom fields / Backup / About / Onboarding), §9.1 demo data generator.

## Task 4: Contacts repository — `shared/src/db/contactsRepo.ts`

**Files:**
- Create: `shared/src/db/contactsRepo.ts`, `shared/src/db/contactsRepo.test.ts`
- Modify: `shared/src/index.ts`

Single async API on top of `DbAdapter`. Every write bumps Lamport via `bumpLamport(db, deviceId)`. All operations transactional.

```ts
export interface ContactsRepo {
  list(opts?: { includeDeleted?: boolean }): Promise<Contact[]>
  getById(id: Ulid): Promise<Contact | null>
  upsert(c: Contact): Promise<Contact>          // sets updated_at, lamport_ts, device_id
  softDelete(id: Ulid): Promise<void>           // sets deleted_at = now, bumps lamport
  restore(id: Ulid): Promise<void>              // clears deleted_at, bumps lamport
  hardDelete(id: Ulid): Promise<void>           // tombstone GC after 30 days; admin-only
  touch(id: Ulid): Promise<void>                // sets last_contacted_at = now (per spec ext#4)
  searchByName(query: string): Promise<Contact[]>  // simple LIKE on display_name + given+family+nickname
  countAlive(): Promise<number>
  recentByLastContacted(limit: number): Promise<Contact[]>
  birthdaysThisMonth(today?: Date): Promise<Contact[]>
  bulkLoad(contacts: Contact[]): Promise<void>  // single transaction; used by demo seeder
}
export function makeContactsRepo(db: DbAdapter, deviceId: string): ContactsRepo
```

Tests: full CRUD round-trip via wa-sqlite; `softDelete` keeps the row but excludes from default `list`; `restore` brings it back; `searchByName` is case-insensitive and matches across display/given/family/nickname; `birthdaysThisMonth` honours frozen date; `bulkLoad` inserts 50 contacts in one transaction (timed sanity check).

**Acceptance:** repo tests pass under wa-sqlite (`@vitest-environment node` + `fake-indexeddb/auto`).
