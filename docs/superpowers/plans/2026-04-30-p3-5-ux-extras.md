### Public API

```tsx
// web/src/ui/ResizeHandle.tsx
interface ResizeHandleProps {
  /** Current width of the panel being resized (px). */
  width: number
  /** Called on every pointer move during a drag (px). */
  onResize: (newWidth: number) => void
  /** Called when the user releases the mouse — persist here. */
  onCommit: (finalWidth: number) => void
  /** Min/max clamps applied internally. */
  min: number
  max: number
  /** 'left' (handle is on the right edge of a left-anchored panel — sidebar)
   *  | 'right' (handle is on the left edge of a right-anchored panel — detail). */
  edge: 'left' | 'right'
}

export function ResizeHandle(props: ResizeHandleProps): JSX.Element | null
```

`null` is returned on touch devices (feature detection at module load).

### Behaviour

- 4 px wide vertical bar with hover state `bg-sky-500/30`. While dragging, body cursor becomes `col-resize`, body `user-select: none`.
- Drag math: capture starting clientX + starting width on mousedown; compute delta on mousemove; clamp to `[min, max]`; call `onResize`.
- On mouseup: detach listeners, call `onCommit(finalWidth)`.
- Use `pointerdown` / `pointermove` / `pointerup` for cross-browser consistency.

### Persistence

In `SmartContactsApp.tsx`:

```ts
// Restore widths from meta.layout_widths_v1 once db is ready.
const layoutWidths = useMemo(() => {
  const raw = metaSettings.layout_widths_v1
  if (!raw) return { sidebar: 224, detail: 384 } // default
  try {
    const parsed = JSON.parse(raw) as { sidebar?: number; detail?: number }
    return {
      sidebar: clamp(parsed.sidebar ?? 224, 180, 480),
      detail: clamp(parsed.detail ?? 384, 240, 640),
    }
  } catch {
    return { sidebar: 224, detail: 384 }
  }
}, [metaSettings.layout_widths_v1])

const [sidebarWidth, setSidebarWidth] = useState(layoutWidths.sidebar)
const [detailWidth,  setDetailWidth]  = useState(layoutWidths.detail)

const persistWidths = useCallback(
  (next: { sidebar: number; detail: number }) => {
    void saveMeta('layout_widths_v1', JSON.stringify(next))
  },
  [saveMeta],
)
```

Wire `<ResizeHandle>` between Sidebar and Main, and between Main and ContactDetail. Sidebar/Detail use inline `style={{ width: <px> }}`; Main is `flex-1`.


### ContactRow

```tsx

  e.dataTransfer.setData(DND_MIME, contact.id)
  e.dataTransfer.effectAllowed = 'copy'

```

### Sidebar drop targets

Each group / tag / organization chip becomes a drop target. Pseudo:

```tsx
<button
  onDragOver={(e) => {
    if (e.dataTransfer.types.includes(DND_MIME)) {
      e.preventDefault()
      setDropTarget({ kind: 'group', id: g.id })
    }
  }}
  onDragLeave={() => setDropTarget(null)}
  onDrop={async (e) => {
    e.preventDefault()
    const id = e.dataTransfer.getData(DND_MIME)
    if (!id) return
    await onAddContactToGroup(id, g)
    setDropTarget(null)
  }}
  className={`... ${dropTarget?.id === g.id ? 'ring-2 ring-sky-500/60' : ''}`}
>
```

`onAddContactToGroup` / `onAddContactToTag` / `onAddContactToOrganization` are passed from `SmartContactsApp` and call `contactsRepo.upsert(updatedContact)`. Mirror-rule semantics:

- **Group**: append `{ id: g.id, name: g.name }` if not present.
- **Tag**: append name if not present.
- **Organization**: append `{ name, current: false }` if not present (current=false because user is just classifying, not declaring active employment).

After upsert, fire a toast: `t('actions.added_to_group', { name })`.

### deriveLookups extension

```ts
// shared/src/core/lookup.ts
export interface Lookups {
  // ... existing fields ...
  organizations: Array<{ name: string; count: number; mostRecentUpdate: string }>
}
```

Algorithm:
1. Iterate alive contacts (`!deletedAt`).
2. For each `c.organizations[]`, accumulate by `name` (case-sensitive — Google semantics).
3. Track per-name the max `c.updatedAt` seen.
4. Sort by `mostRecentUpdate` DESC; break ties alphabetically.
5. Return `slice(0, 50)`.

### Filter

```ts
// web/src/ui/useFilteredContacts.ts
if (filters.organization) {
  filtered = filtered.filter((c) =>
    (c.organizations ?? []).some((o) => o.name === filters.organization),
  )
}
```

### Sidebar section

Same shape as the Tags section. Active state highlighted with `bg-sky-600/20 text-sky-300`. `×` to clear filter. Empty state shows em-dash placeholder when `lookups.organizations.length === 0`.
